# Content

Authored game data and curriculum, independent of runtime code. Phase 1 lives under `phase1/` (see that README).

| Path | Role |
| --- | --- |
| `phase1/` | Phase 1 scenes, words, world, voices, ambient, audio map |
| `phase1/scene-list.md` | Curriculum plan (human-readable) |

## Commands

```bash
npm run check:content
npm run check:content:strict
npm run tts:dry
npm run tts
npm run tts:validate
```

Preview: `npm run dev`, then open `/preview.html`.
