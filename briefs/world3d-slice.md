# world3d vertical slice: three.js front end for silver-tongue core, using our assets

## Goal
A playable browser build where the player walks a 3D street built from our GLBs, walks into a place zone (→ `goTo`), taps an NPC (→ `talkTo`/`startScene`), sees NPC lines in a speech bubble with tap-to-gloss, picks a reply, and the wallet/day HUD updates — all driven by Jamil's `@silver-tongue/core` (`core.send(input) → GameEvent[]`). Same save format as his TUI. This is `packages/world3d` in a local clone of his repo.
