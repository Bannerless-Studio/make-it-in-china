# Rig + animate the characters procedurally in Blender (no more T-pose)

Follow briefs/assets-common.md rules (you MAY edit tools/blender/lib/ and sets/characters.py; no other Blender worker is running). Do not touch silver-tongue/.

## Goal
Every human character GLB in assets/characters/ ships with a shared skeleton and baked animation clips, in a relaxed arms-down rest pose, so the game plays them with three.js AnimationMixer. Pets get a minimal rig with idle. Rebuilding via build_all.py regenerates everything.

## Contract with the game (fixed — the world3d worker is coding against this now)
- Clip names, exactly: `idle`, `walk`, `talk`, `carry_idle`, `carry_walk`. Pets: `idle` only. Props: none.
- Rest pose: arms hanging ~15° from the body (relaxed A), feet on origin, facing +Z in glTF (front = -Y in Blender, as before).
- Skeleton names (Mixamo-like so retargeting later is easy): Hips, Spine, Chest, Neck, Head, LeftShoulder, LeftArm, LeftForeArm, LeftHand, RightShoulder, RightArm, RightForeArm, RightHand, LeftUpLeg, LeftLeg, LeftFoot, RightUpLeg, RightLeg, RightFoot. Same hierarchy on all humans (kid too, scaled).
- Hand attachment: an empty/bone named `RightHandGrip` and `LeftHandGrip` at the palm, and `HeadTop` on the head — the game attaches held props and speech bubbles there. Export bones only (glTF has no empties inside skins — make them leaf bones).
- Loop: idle/walk/carry_* loop seamlessly (first == last frame). talk is 2 s loopable. 24 fps. walk cycle 1 s = 2 steps; stride ~0.6 m at 1.7 m height (report the actual root-motion-free stride so the game sets speed = stride / cycle).
- No root motion; walk is in place.

## Approach
- characters.py already builds bodies from named parts (head, torso, arm segments, legs, hair, headwear, outfit pieces). Add a rig stage: build the armature from Body proportions, then assign each part to its bone with rigid weights (each vertex 1.0 to one bone) — chunky style, no deformation needed. Outfit pieces bind to the nearest limb/torso bone. Headwear + hair → Head. Bevel joints where arm/leg segments meet so the gap doesn't open when bent (use overlapping capsule ends).
- Rest pose change: rotate the arm parts down at build time (so the mesh's bind pose is the relaxed pose), or bind in T and set a rest-pose action; the exported bind pose must be the relaxed pose either way.
- Animations as keyframed actions on the armature, generated by functions (sine-based idle breathe + weight shift; walk with hip sway, arm counter-swing, knee bend, foot lift; talk = head nods + one-hand gesture; carry = forearms up holding at chest, walk variant). Bake to NLA / export with `export_animations=True`, `export_nla_strips=True` or the actions list so each clip appears by name in the GLB.
- Pets: 4-bone rig (Root, Spine, Head, Tail) + idle (breathe + tail swish).
- Write `tools/blender/lib/rig.py` (armature build, rigid bind, clip generators) so other sets/characters could reuse.
- Verification: write `tools/blender/verify_rig.py` that re-imports each GLB headless and asserts: armature present, bone names exact, clip names exact, each clip duration, first==last frame for loops, mesh has 1 skin; plus renders `assets/characters/sheet_pose.png` (rest pose) and `assets/characters/sheet_walk.png` (frame 12 of walk) — look at both.
- Update characters manifest: `rig: {skeleton: "st-human-v1", clips: [...], stride_m, grip_bones}`.
